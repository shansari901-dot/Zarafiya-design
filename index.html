❓ Kaise Use Karein

  1. Setups tab mein jao, machine ka naam, hooks, format daalo → Save.
  2. Design tab mein canvas pe draw karo, ya BMP upload karo.
  3. Convert tab mein setup select karo, canvas ya file choose karo → Convert.
  4. Download button aa jayega — file machine mein daalo.

⚠️ Note: Yeh basic EP/BMP writer hai. Asli machine formats mein cramming bits, feeder info, aur compression ho sakti hai. Test karke apni machine ke hisaab se tweak karein.

💡 Color Rules

• White pixel = Hook Lift (solenoid ON)
• Black pixel = Hook Lower (solenoid OFF)
