❓ Naya Flow (v2.0)

  1. Setups tab → apni machine ki running file (EP/JC5/BMP) upload karo.
  2. App khud hooks, picks, takan sab nikaal lega aur form mein bhar dega.
  3. Setup ko ek naam do (e.g. "Bonas 1344") aur Save karo. Ek baar ka kaam.
  4. Design tab → naya design banao ya upload karo.
  5. Convert tab → wahi saved setup select karo, picks/repeat set karo → Convert.
  6. File download ho jayegi — machine mein daalo. Bas!

💡 Rules

• White pixel = Hook Lift (solenoid ON)
• Black pixel = Hook Lower (solenoid OFF)
• Picks = rows = weft insertions
• Hooks = columns = warp threads

⚠️ Note

Parsing EP/JC5 files ka header reverse-engineered hai. Agar teri file ka format alag hai (jaise Grosse, Schleicher), toh file reject ho sakti hai. Us case mein manual form fill kar lena — baaki sab same kaam karega.
